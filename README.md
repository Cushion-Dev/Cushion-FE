# 프로젝트 소개

> 쿠션은 **해야 할 말이나 하고 싶은 말을 부드럽게 제시해 주는 챗봇 서비스**입니다.  
> 대화 내역을 첨부하면 CLOVA OCR으로 내용을 추출하고, CLOVA STUDIO를 사용해 사용자의 성향을 파악한 뒤 부드럽게 메시지를 변환해 줍니다.

<br/>

**‘모르고’, ‘어렵고’, ‘못하는’ 사람들에게**는 해결 방법을 제시하기보다, **해결해 주는 서비스**가 필요하다고 판단했습니다. 

- **설정한 사용자와 상대방의 관계가 반영**되도록 **프롬프트 작성 및 튜닝**
- 사용자가 입력한 메시지를 **부드럽게 변환**하기 위한 **프롬프트 작성 및 튜닝**
- 사용자가 제시한 타 메신저 **캡처 이미지에서 텍스트를 리딩**할 수 있도록 **네이버 클로바 OCR**

프로젝트 개발 기간: 2024.07.19. ~ 2024.08.08. (2주)

<br/>
